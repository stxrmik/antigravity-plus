# Antigravity Plus

Claude Code-style discipline plugin (`0.31.0`) for **Google Antigravity** Desktop 2.x and the **Antigravity CLI** `agy` (verified: Desktop 2.35.2, CLI 1.5.18): 36 skills, 7 subagents, 6 hooks (5 events), 19-tool bundled stdio MCP server, always-on rules, 4-tab Control Center sidecar (Desktop), selectable **modules** (`modules.py`), a two-way **Claude Code ↔ Antigravity** bridge. Python 3.8+ stdlib (+ Node 24 for the sidecar); macOS, Linux, Windows.

## Commands
- Install / update (`~/.gemini/config/plugins/antigravity-plus`, read by Desktop and CLI): `./install.sh` (Windows: `.\install.cmd` or `python3 install.py`); `--choose`, `--list`, `--modules core,git`, `--without mobile`, `--all`, `--no-claude`, `--lang ru|en`, `--plain`, `--demo` (made-up data, changes nothing); choice in `~/.gemini/antigravity-plus/modules.json`; module `claude` → `~/.claude/skills/antigravity`
- Bridge: `python3 claude-code/skills/antigravity/scripts/delegate.py budget [--claude-5h|--claude-week PCT]` (also `models|estimate|run|next|series|wait|watch|reply|result|diff|send|cancel|list|settings|wake`; agents run `ask`/`tell`). Reverse: `python3 antigravity-plus/skills/claude/scripts/claude_task.py budget|run|wait|result|diff|send|cancel|list`
- Update / rollback / uninstall: `./install.sh --update` (= `/update`: `skills/update/scripts/update.py run|status|check|rollback`), `./install.sh --uninstall` (`--purge` also removes `~/.gemini/antigravity-plus`)
- Tests (offline, temp `HOME`): `python3 tests/run_tests.py [test_speed]`; replay / live probes: `python3 tests/replay.py [--limit 25]`, `tests/live_smoke.py`, `tests/live_mobile.py [--ios|--android]`, `tests/live_cli.py`, `tests/live_cli_bridge.py`
- Health: `python3 antigravity-plus/skills/doctor/scripts/doctor.py [--install-check]`; usage: `skills/usage/scripts/usage.py --all --days 7` (also `context.py`, `insights.py`); client data: `python3 antigravity-plus/hooks/client.py show|refresh|export`
- LSP CLI: `python3 antigravity-plus/skills/lsp/scripts/lsp.py servers|def|refs|calls|hover|impl|type|symbols|find|check|rename|status|stop`

## Architecture
- `antigravity-plus/plugin.json` (strict JSON: `agy plugin install` can't read `//` comments), `hooks.json` (`SessionStart`, `PreInvocation`, `PreToolUse`, `PostToolUse`, `Stop`; matchers cover old tool names), `mcp_config.json` (`antigravity-plus_tools`). `install.py` rewrites `python3` → `py -3 -X utf8` on Windows.
- `antigravity-plus/mcp/server.py` — stdio JSON-RPC 2.0, 19 tools (`lsp_*`, `ci_*`, `deps_audit`, `ui_check`, `mobile_*`, `memory_search`, `git_state`, `quota`); `tools/list` shows only installed scripts; `AGP_MCP_TIMEOUT` caps tool time; a timed-out tool returns partial output.
- `antigravity-plus/hooks/` — runtime hooks & state (`~/.gemini/antigravity-plus/state/`):
  - `client.py` — models, efforts, «New»/«Leaving …» tags, default model, windows (`CASCADE_USE_EXPERIMENT_CHECKPOINTER.max_token_limit`), Orchestrator executor, aliases, version — from Antigravity itself (`GetAvailableModels`; CLI-only: `agy models`) → `~/.gemini/antigravity-plus/client.json` (TTL 6 h / new version; SessionStart spawns `refresh`, hooks only read); fallback `client-snapshot.json` (`export`). `resolve(family, effort)`: a gone family → its same-word successor, else "". By hand: prices, tier order, `PCT_PER_USD`, thresholds.
  - `session_start.py` — git snapshot, `AGENTS.md`/`CLAUDE.md` bridge (past 24,000 bytes or the `rules-token-budget`: a one-line `read_file` warning), recent conversations, memory, mobile/CI detection, `is_subagent` (`parentConversationId`), `user_markdown` `uiNotices`.
  - `instructions.py` — `PreInvocation` (`systemMessage` + `user_markdown`): constraints, edit errors, peers (`coord.py`), Orchestrator handoffs, `parallel.py`, `speed.py` (context/sandbox/error loops; the Antigravity CLI's `AGY_CLI_AUTO_COMPACT_OVERRIDE`), `quota.py`, `progress.py` (after a failed background command or 8+ silent calls), `memory_hints.py`, `facts.py`, `objective.py`.
  - `guard.py` — `PreToolUse` (`run_command`, `write_file`, `edit_file`, `read_file`, `exit_plan_mode`): destructive cmds, user bans (AST read-only `ssh … python3` exempt), `overwrite` auto-fixes (git flags, `BypassSandbox`), `check_plan`, secrets, stale-write diffs; `agent-settings`: Antigravity/plugin/MCP/hooks config, sidecar `/api/(toggle|lsp/stop)`, mutating LS RPCs (`Set|Update|Install|Toggle|Grant|Reset*`, `Delete*`, triggers, terminal input, OAuth), `SELF_SWITCH` (Bypass words via agentapi, `Send*Message`, `agy -p|-i|-c|-r`), decoded (`%XX`, `$'…'`, globs); `ManageSidecar` allowed; `conversation-delete` (`DeleteConversation`, `DELETE /v1/conversations/<id>`; `force_ask`); `agy_verdict`: skip-permissions, `--mode auto|accept-edits`, `--sandbox=false` → `protection-off`; `--settings` → `agent-settings`; `plugin|mcp install…`, `install|update`, remote control, `mic-serve` → `agent-tools`; Bypass Mode (`auto_approve` except `SYSTEM_RULES` & user bans). Limits (`procs.py`, `agy` counts as agent root; Bypass too): `agentPriority`, `heavyMax`/`heavyPrograms` (wait ≤ 20 s, then deny).
    - `SYSTEM_RULES` (ask even in Bypass Mode): disk format, power, security-off, sudo/admin, autostart, `kill -9 -1`, fork bombs, secret/private-key reads, `rm` of `/` or `~`, system/protected files, the agent's own settings/tools/permissions (`agent-settings`, `agent-tools`, `protection-off`, `agent-limits`, `claude-permissions`), `scheduled-sidecar`.
    - `LOCAL_RULES` (this computer only): the system/protected-file, sudo/admin, autostart, security-off and agent-own rules, `scheduled-sidecar`, `conversation-delete`. Text for another machine (`ssh` strings/heredocs, `*ssh*` wrappers, `docker|podman|kubectl exec`) drops them; wiping `/` or a disk, power, `kill -9 -1`, key reads and project bans still stop. `guard.py --test "<cmd>" --bypass`.
  - `check_edit.py` & `checks.py` — `PostToolUse` syntax/linter checks.
  - `stop.py` — honors `continuationActive`; in plan mode (`in_plan`, `plan_execute:true`) only `facts_check`/`objective_check`, `task.md` after `handed_over()`; checks background, `task.md`, syntax, unverified UI/mobile/code, CI after push, announce-only turns, agreed-without-looking, memory. Every reason ends with `AFTER` (`with_after()`): act first, then 1–3 lines of what changed, never the shown answer again (Stop takes only `decision`/`reason`). `facts.py` spares paths the agent wrote or read, «FAIL …» lines, repeats.
  - `orchestrator.py` — classic & configurable Orchestrator + `/plan` (`is_plan_execute`): `check_plan` (plans vs bans & missing verification), `handoff_message`, `in_plan_mode`, `handed_over`; executor from `client.executor()`; markers count only at the start of a SYSTEM_MESSAGE body in the current turn.
  - `conversation.py` & `compat.py` — transcript parser (user msgs, bans, full access, Bypass switch); OS layer (locks, atomic replace, processes/ports, `language_server()`), `data_dirs()`/`data_dir(transcript)` (Desktop `~/.gemini/antigravity`, CLI `~/.gemini/antigravity-cli`; conversations are looked up in both), `runtime(payload)`, `agy()`, `agy_version()` (≤ 2 s, off the hot path), `agy_headless()`, `tool(name)`.
  - `gitcheck.py` — git/gh commands that hang in the agent terminal (guard denies with the working form), half-done rebase/merge/cherry-pick/revert/bisect, conflict markers; setting `gitChecks`.
- `skills/update/scripts/update.py` — a release = a higher `version` in plugin.json, notes = «Antigravity Plus X.Y.Z: …» commit subjects. SessionStart runs `update.py background` daily; `run` fast-forwards a clean clone or downloads into `~/.gemini/antigravity-plus/source`, keeps `previous/` for `rollback`, restarts the sidecar if `server.mjs` changed; `AGP_UPDATE_CHECK=off`.
- `skills/<name>/` — `SKILL.md`, `scripts/` (`usage/pricing.json`: rates, fallback windows). Doctor checks the CLI and client data; `/schedule-task` needs Desktop.
- `skills/lsp/scripts/lsp.py` — LSP client: `LANGS`/`SERVERS`, `~/.gemini/antigravity-plus/lsp.json`, root `ROOTS` (outermost `pyrightconfig.json`/`buildServer.json`/`settings.gradle*`, else the nearest project file), a detached `lsp.py daemon` per (server, root) (`AGP_LSP_IDLE` 600 s, `AGP_LSP_MAX` 3). `refs`/`calls` add a text cross-check of files the server didn't link. Hooks: `session_lines()`, `edit_problems()` (new errors vs `git show HEAD:`), `search_hint()`.
- `agents/*.md` — read-only `code-reviewer`, `security-auditor`, `explorer`, `researcher`; write-capable `worker`, `debugger`, `test-writer`.
- `rules/*.md` — `AGENTS.md` (core); per module `FACTS.md`, `OBJECTIVE.md`, `MEMORY.md`, `PARALLEL.md`, `GIT.md`, `LSP.md`.
- `modules.py` — per module: skills, agents, rules, sidecars; `off` (settings forced off without it, via `memory.settings()`); `needs` (tools); `keep` (scripts installed anyway); `claude`; bilingual details; `GROUPS`/`GROUP_OF` (menu headings). `install.py` stages a filtered copy (rules lose left-out commands' rows, list items and `<!-- needs:<skill> -->` lines), writes `modules.json`, copies `compat.py`, `client.py`, `client-snapshot.json` next to `delegate.py`.
- `installer_ui.py` (stdlib) — rich/plain screens (truecolor→256→16, `NO_COLOR`, Windows VT); a UI failure → plain; agent terminals (`TERM=dumb`, `CLAUDECODE`, `CI`, `ANTIGRAVITY_AGENT`) always plain, no menu — `update.py` and tests parse plain lines. Language: `--lang` → saved → OS → locale → English.
- `antigravity-plus/sidecars/usage/` — Control Center 2.0 (`server.mjs`, `index.html`, `status.py`): usage, quotas, client version, agents/bridge/LSPs, `/api/toggle` allowlist, updates, redacted `guard.log`.
- `claude-code/skills/antigravity/` — `SKILL.md`, `delegate.py` (`agentapi`, `WaitForConversationFullyIdle`, `CORTEX_STEP_STATUS_WAITING`, `GetCascadeTrajectorySteps|GetTrajectoryFileDiffs`), `agy_cli.py` (`--via auto|desktop|cli`: a detached `cli-turn` per turn runs `agy -p … --output-format stream-json --mode accept-edits`, then `--conversation <cid>`; never skip-permissions/`--settings`; `denied_actions` → exit 2; no quotas without Desktop). Delegated runs carry `conversation.DELEGATED_MARK` (fewer nudges). The agent's `ask|tell` print a `{"to_claude_code": …}` line that `listen()` finds in RUN_COMMAND output or a SYSTEM_MESSAGE `agentMessage`; `wait` exits 4 on a question. IDLE while `WaitForConversationFullyIdle` blocks = `background` (`idle_state()`). `auto_resume()` answers an error turn with «go on» (≤ `retries_max`); `--max-parallel` queues `q-…` for `dispatch()`/`supervise`; `watch` claims events; `--owner` keeps a shared `watch` off other agents' tasks. `--model orchestrator` = Orchestrator (Carbon) (`fuzzy()`). guard auto-approves the installed script alone (`talks_to_claude()`); Stop waits in `waiting_for_claude()`.
- `tests/` — offline tests; fakes in `tests/probe/`.

## Conventions
- **Zero external deps:** Python 3.8+ stdlib only (`from __future__ import annotations`); hooks on macOS often get `/usr/bin/python3` (3.9); CI: 3.9 & 3.13 on Ubuntu/macOS/Windows.
- **Cross-platform I/O:** `hooks/compat.py` for locks and atomic replace; `-X utf8` and `encoding="utf-8", errors="replace"` on `subprocess(..., text=True)` (Russian Windows pipes are cp1251); no invalid string escapes (`r"""…"""`). `tests/test_names.py` enforces both.
- **Public repo hygiene:** no real hostnames, emails, private project names, bundle IDs, device names, user quotes — synthetic examples.
- **Rule files:** `antigravity-plus/rules/*.md` need `trigger: always_on` frontmatter, `< 24 KB`; keep repo `AGENTS.md` `< 18.5 KB` (Antigravity's 20,000-token `rules-token-budget`).
- **Models:** never hard-code an id, label, window or leaving date `client.py` knows; tiers are (family, effort) rules.

## Gotchas
- Repo edits do **not** affect the live install until `./install.sh` runs.
- `sidecar_sdk` verifies `X-Sidecar-Token` only on non-GET requests: register stateful Control Center endpoints with `app.api(path, fn)` (POST), never `'GET'`.
- Automations (2.32.2, Desktop): `~/.gemini/config/sidecars/<id>/sidecar.json` with `"builtin": "schedule"`, `"args": ["CRON_TZ=<zone> <cron>", "agentapi", "new-conversation", "--", "<prompt>"]`, `"restart_policy": "always"`, `display_name`, `agent_permissions`; only the user enables one; unattended runs deny ungranted commands. `/schedule-task` owns `agp-*` (`scheduled-sidecar`).
- `server.mjs` needs a `ManageSidecar` restart of `antigravity-plus/usage` (`index.html`, `usage.py`, `pricing.json` reload per request).
- Desktop LS (2.34.0+): no CSRF token in argv; it writes `~/.gemini/antigravity/daemon/hub_<httpPort>.json` (0600: `pid`, `httpsPort`, `httpPort`, `lsVersion`, `csrfToken`). Agent terminals/sidecars get `ANTIGRAVITY_LS_ADDRESS` + `ANTIGRAVITY_CSRF_TOKEN`, hooks only `ANTIGRAVITY_CONVERSATION_ID`, MCP only `PLUGIN_ROOT`/`PLUGIN_DATA`. Use `compat.language_server()`: env → daemon file → `--csrf_token` (≤ 2.33). Never `os.kill(pid, 0)` on Windows: it kills.
- CLI: each `agy` run is its own LS (random ports, no hub file); agent commands get the LS env plus `ANTIGRAVITY_AGENT=1`, `ANTIGRAVITY_LS_VERSION=cli-<ver>`. A CLI hook would find the Desktop LS, which doesn't know its conversation: `language_server(conversation=True, payload=…)` → None. The terminal sandbox (on by default) blocks localhost and `ps`: no quotas from headless. Transcript: `~/.gemini/antigravity-cli/brain/<cid>/.system_generated/logs/transcript_full.jsonl`. Hooks see `write_file`/`read_file`/`run_command`, but headless `init.tools[]` lists old names (`view_file`, `write_to_file`): use `compat.tool()`. Headless «ask» = denial (`denied_actions`): CLI reasons address the agent. No sidecars.
- Agent terminal: TTYs, `TERM=dumb`, `PAGER=cat`, `GIT_EDITOR=false` (use `GIT_EDITOR=true git …`); keyboard prompts hang.
- Hooks read settings via `skills/memory/scripts/memory.py` (kept without the memory module); skill-backed nudges check the script exists.
- LSP: pyright knows only open files until «Found N source files» (`Session.ready`); sourcekit-lsp needs `buildServer.json` and a fresh build; kotlin-lsp needs the Gradle root and `kill_tree`.
- `agents/*.md` goes through `filter_rules`: a `<!-- needs:<skill> -->` line vanishes without that skill — keep such lines single.
- Never name a function `top`: `tests/test_names.py` (`symtable`, 3.9) takes its parameters for globals.
- Hooks never crash on bad input and never call the LS or network on the hot path; `PreToolUse` returning `{}` means **deny** (`{"decision": "allow"}` passes).
- Bypass Mode: `/bypass`, `/bypass off`; `bypassMode` {on, at, since, conversation, n} in `settings.json`, set only by typed user messages (not briefs, subagents, `agentapi`, headless `agy -p`/`agy acp`), applied once per conversation (`bypass_applied`), only if newer than `at`: an old «/bypass» never undoes a later «/bypass off».
- `delegate.py` runs with copies of `compat.py`/`client.py`; `MARK` = `conversation.DELEGATED_MARK`, `ANSWER`/`MESSAGE`/`FOLLOW_UP` match `conversation.CLAUDE_SAYS`. An unknown `--model` is an error with near matches (`agentapi` silently takes flash).
- `usage.py`: a call's model = its PLANNER_RESPONSE step's `model` (Desktop 2.35.2+, CLI; mid-turn switches count), else `started_on()` (task record → `GetCascadeTrajectoryGeneratorMetadata` → `conversation-models.json` → `client.default_model()`); not in pricing.json → by family, else «price unknown»; LS via `compat.daemon_servers()` (`ProxyHandler({})`). `AGY_CLI_AUTO_COMPACT_OVERRIDE` (`800K`, `80%`) is an Antigravity CLI setting only; the desktop app ignores it. `claude_limits()` only changes `advice()`.
- Orchestrator (fixed `gemini-pro-orchestrator[-argon|-neon]`; configurable Planner/Executor in Settings > Models and `/plan`, 2.34+): the planner hands over with `exit_plan_mode` («Plan mode is off: this turn runs on the execution model»), `enter_plan_mode` hands back («[plan review] … planning model»; both SYSTEM_MESSAGE bodies). Configurable sessions omit `"orchestrator"` from `modelName`, set `plan_execute:true` in `<appDataDir>/annotations/<cid>.pbtxt` (`is_plan_execute()`) and alone default to High effort. A call's `stepIndices` start at its PLANNER_RESPONSE step. Quota groups list «Orchestrator (Carbon)» whole: `delegate.group_of()` matches label and family.
- Quota: `RetrieveUserQuotaSummary {"forceRefresh": true}`; the plain call is cached ~5 min (made Orch (Carbon) look ~7× cheaper than Carbon (High); really 10–15%). Each call is booked at its API price (per token Hydrogen 1, Neon 2, Carbon ~4). Claude group ≈ 2.5% of its week per API $ (Gemini ≈ 0.042%).
- Tiers (measured order; Neon $3/$15/$0.15): `fast` Hydrogen Low → Hydrogen Medium → Neon Low → Claude Sonnet 5.5 Low; `standard` Hydrogen Med → Neon Low → Hydrogen High → Neon Med → Sonnet Med; `strong` Neon Med → Hydrogen High → Neon High → Hydrogen XHigh → Orch Neon; `ultra` Carbon High → Orch Carbon → Carbon Med → Neon High; `claude` Sonnet → Opus. `client.resolve()` gives live ids (`LEGACY_IDS` without a snapshot); Experimental = live models in no tier, with the client's tags. AI Pro got Neon + Orch (Neon), not Carbon.
- Benchmarks: 2026-11-20 (48 runs, 16 models; all right but Hydrogen (Low) once; Carbon (High) & Orch (Carbon) 11–26 min, never better) and 2026-11-24 (20 runs; every Carbon (High)/Orch (Carbon) run hit the 9-minute cap). Don't lower `--timeout` (default 1800 s) for `ultra`.
- A new conversation's first call is uncached (~41k tokens); later ~90% cached: chain work with `run --series` + `next`.
- Context windows (`maxContextTokens`, server-side; no `compaction_threshold`): a recent call's (`hooks/context_window.py`, < 24 h) → `client.window()` → pricing.json. Compaction when the next call won't fit (`use-model-reported-token-count`; max seen 511.8k of 512k). `speed.ctx_limits()` warns at 200k/440k (512k), 150k/220k (256k), 80k/110k (128k), 50k/70k (80k).
- An injected `systemMessage` persists until compaction: hint only on state changes. `doctor.py` checks `RULE_FILE_LIMIT` (24,000 bytes).
