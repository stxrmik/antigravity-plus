# Antigravity Plus

Claude Code-style engineering discipline plugin (`0.30.1`) for **Google Antigravity 2.x** (verified on 2.35.1): 36 skills, 7 subagents, 6 hooks (5 events), 19-tool bundled stdio MCP server, always-on rules, 4-tab Control Center sidecar, selectable **modules** (`modules.py`), and a two-way **Claude Code ↔ Antigravity** bridge. Pure Python 3.8+ stdlib (+ bundled Node 24 for the usage sidecar); macOS, Linux, Windows.

## Commands
- Install / update (`~/.gemini/config/plugins/antigravity-plus`): `./install.sh` (Windows: `.\install.cmd` or `python3 install.py`); `--choose`, `--list`, `--modules core,git`, `--without mobile`, `--all`, `--no-claude`; the choice is saved in `~/.gemini/antigravity-plus/modules.json`; the `claude` module installs into `~/.claude/skills/antigravity` when `~/.claude` exists
- Bridge (Claude Code → Antigravity): `python3 claude-code/skills/antigravity/scripts/delegate.py budget [--claude-5h PCT] [--claude-week PCT]` (limits, week forecast, tier picks, advice; also `models`, `estimate`, `run`, `next`, `series`, `wait`, `watch [--follow]`, `reply`, `result`, `diff`, `send`, `cancel`, `list`, `settings`, `wake`, `statusline`; `supervise` starts itself; agents run `ask`/`tell`). Reverse: `python3 antigravity-plus/skills/claude/scripts/claude_task.py budget|run|wait|result|diff|send|cancel|list`
- Update / rollback / uninstall: `./install.sh --update` (= `/update`: `skills/update/scripts/update.py run|status|check|rollback`), `./install.sh --uninstall` (`--purge` also removes `~/.gemini/antigravity-plus`)
- Tests (offline, isolated temp `HOME`): `python3 tests/run_tests.py` · one suite: `python3 tests/run_tests.py test_speed`
- Replay / live smoke: `python3 tests/replay.py [--limit 25]`, `tests/live_smoke.py`, `tests/live_mobile.py [--ios|--android]`
- Health: `python3 antigravity-plus/skills/doctor/scripts/doctor.py [--install-check]`; usage: `skills/usage/scripts/usage.py --all --days 7` (also `context.py`, `insights.py`)
- LSP CLI: `python3 antigravity-plus/skills/lsp/scripts/lsp.py servers|def|refs|calls|hover|impl|type|symbols|find|check|rename|status|stop`

## Architecture
- `antigravity-plus/plugin.json`, `hooks.json`, `mcp_config.json` — manifest, hook wiring (`SessionStart`, `PreInvocation`, `PreToolUse`, `PostToolUse`, `Stop`), bundled MCP server (`antigravity-plus_tools`). `install.py` rewrites `python3` → `py -3 -X utf8` on Windows.
- `antigravity-plus/mcp/server.py` — stdio JSON-RPC 2.0 server, 19 tools (`lsp_*`, `ci_status`, `ci_failure_logs`, `deps_audit`, `ui_check`, `mobile_ui`, `mobile_act`, `memory_search`, `git_state`, `quota`). `tools/list` shows only installed scripts; `AGP_MCP_TIMEOUT` caps tool time limits; a timed-out tool returns partial output.
- `antigravity-plus/hooks/` — runtime hooks & state (`~/.gemini/antigravity-plus/state/`):
  - `session_start.py` — git snapshot, `AGENTS.md`/`CLAUDE.md` bridge (a one-line `read_file` warning, never inlined, past the 24,000-byte file limit or the 20,000-token `rules-token-budget`), recent conversations, memory index, sandbox memory, mobile/CI detection, `is_subagent` (`parentConversationId`), zero-token `user_markdown` `uiNotices`.
  - `instructions.py` — `PreInvocation` dispatcher (`systemMessage` + `metadata.user_markdown`): user constraints, `check_edit.py` errors, active peers (`coord.py`, `HookArgsCommon` ids), Orchestrator handoffs/reviews, `parallel.py`, `speed.py` (context/sandbox/error-loop hints; the Antigravity CLI's `AGY_CLI_AUTO_COMPACT_OVERRIDE`), `quota.py` (`quotaHints`), `progress.py` (`progressHints`: updates after a failed background command or 8+ silent calls), `memory_hints.py`, `facts.py`, `objective.py`.
  - `guard.py` — `PreToolUse` (`run_command`, `write_file`, `edit_file`, `read_file`, `exit_plan_mode`): destructive cmds, user bans (AST read-only `ssh … python3` exempt), `overwrite` auto-fixes (git flags, learned `BypassSandbox`), `orchestrator.check_plan`, secrets (`secret_print` strips `VAR=val` prefixes), `coord.py` stale-write diffs, `agent-settings` (Antigravity/plugin settings, MCP config, `projects/`, `plugins/`, sidecar `/api/(toggle|lsp/stop)`, `SELF_SWITCH` (`/bypass` via agentapi, `CreateConversation`, `SendUserCascadeMessage`, `StartCascade`), LS RPCs `Set|Update|Install|Uninstall|Toggle|Revoke|Grant|Disconnect|Reset*`, `HandleCascadeUserInteraction`, `CreateCustomizationFile`, `Delete*`, decoded (`%XX`, `$'…'`, `/./`, globs, `NAME=value`); text programs and gh/glab text options exempt; `ManageSidecar` allowed even in Bypass Mode), `conversation-delete` (`DeleteConversation`, `DeleteCascadeTrajectory`; `force_ask`, bypassed in Bypass Mode), Bypass Mode (`auto_approve` except `SYSTEM_RULES` & user bans). Limits (`procs.py`, Bypass Mode too): `agentPriority` (detached `procs.py lower`), `heavyMax`/`heavyPrograms` (wait ≤ 20 s, then deny).
    - `SYSTEM_RULES` (ask even in Bypass Mode): disk format, power, security-off, sudo/admin, autostart, `kill -9 -1`, fork bombs, secret/private-key reads, `rm` of `/` or `~`, system and protected files, the agent's own settings/tools/permissions (`agent-settings`, `agent-tools`, `protection-off`, `agent-limits`, `claude-permissions`), `scheduled-sidecar`.
    - `LOCAL_RULES` (protect only this computer): the system/protected-file, sudo/admin, autostart, security-off and agent-own rules above, `scheduled-sidecar`, `conversation-delete`. Text for another machine or container (quoted strings/heredocs of `ssh`, `*ssh*` wrappers like `./deploy/ssh.sh`, `docker|podman|kubectl exec`) drops them; wiping `/` or a disk, power commands, `kill -9 -1` and key reads still stop it, as do project bans. `guard.py --test "<cmd>" --bypass`.
  - `check_edit.py` & `checks.py` — `PostToolUse` syntax/linter checks.
  - `stop.py` — honors `continuationActive`; in Orchestrator plan mode (`in_plan=True`, incl. `plan_execute:true`) skips broken/unverified/setup/review/bg, and `task.md`/`announcement()` only after a hand-over (`handed_over()`), keeping `facts_check`/`objective_check`; checks `stop:background`, `task.md`, syntax, unverified UI/mobile/code, CI after push/PR, announce-only turns, agreed-without-looking, `facts.py`, memory reminders.
  - `orchestrator.py` — classic & configurable Orchestrator + `/plan` (`is_plan_execute`): `check_plan` (`exit_plan_mode` plans vs bans & missing verification), `handoff_message`, `in_plan_mode`, `handed_over`; markers count only at the start of a SYSTEM_MESSAGE body in the current turn.
  - `conversation.py` & `compat.py` — incremental transcript parser (user msgs, bans, full access, Bypass switch); OS layer (locks, atomic replace, process/port discovery, `language_server()`).
  - `gitcheck.py` — git/gh commands that hang in the agent terminal (guard denies with the working form), half-done rebase/merge/cherry-pick/revert/bisect, conflict markers; setting `gitChecks`.
- `antigravity-plus/skills/update/scripts/update.py` — a release = a higher `version` in plugin.json, notes = «Antigravity Plus X.Y.Z: …» commit subjects. SessionStart runs `update.py background` at most once a day; `run` fast-forwards a clean clone (modules.json `source`) or downloads the archive into `~/.gemini/antigravity-plus/source`, snapshots the install into `previous/` for `rollback`, restarts the usage sidecar (`ManageSidecar`) if `server.mjs` changed. `updateCheck`/`autoUpdate`; `AGP_UPDATE_CHECK=off`.
- `antigravity-plus/skills/<name>/` — `SKILL.md`, `scripts/` (`usage/pricing.json`: rates, context windows).
- `antigravity-plus/skills/lsp/scripts/lsp.py` — LSP client: `LANGS`/`SERVERS`, `~/.gemini/antigravity-plus/lsp.json`, project root `ROOTS` (outermost `pyrightconfig.json`/`buildServer.json`/`settings.gradle*`, else the nearest project file), a detached `lsp.py daemon` per (server, root) (Unix socket; TCP + token on Windows): idles out after `AGP_LSP_IDLE` (600 s), max `AGP_LSP_MAX` (3). Positions `<file>:<line> <name>`; `refs`/`calls` add a text cross-check of files the server didn't link. Hooks: `session_lines()`, `edit_problems()` (errors an edit added vs `git show HEAD:`, only from a running server), `search_hint()` (after two rg searches for symbols); setting `lspChecks`.
- `antigravity-plus/agents/*.md` — read-only `code-reviewer`, `security-auditor`, `explorer`, `researcher`; write-capable `worker`, `debugger`, `test-writer`.
- `antigravity-plus/rules/*.md` — `AGENTS.md` (core), `FACTS.md` + `OBJECTIVE.md` (facts), `MEMORY.md` (memory), `PARALLEL.md` (parallel), `GIT.md` (git), `LSP.md` (lsp).
- `modules.py` (repo root) — per module: skills, agents, rules, sidecars; `off` (settings keys forced off without it, via `memory.settings()`); `needs` (tools); `keep` (scripts installed anyway); `claude`; bilingual details. `install.py` stages a filtered copy (rules lose table rows, comma lists and `<!-- needs:<skill> -->` lines of left-out commands), writes `modules.json`.
- `antigravity-plus/sidecars/usage/` — Control Center 2.0 (`sidecar.json`, `server.mjs`, `index.html`, `status.py`): usage, quotas (`RetrieveUserQuotaSummary`), workspace agents/bridge/LSPs, `/api/toggle` allowlist, update checks, redacted `guard.log`.
- `claude-code/skills/antigravity/` — `SKILL.md` + `scripts/delegate.py`: `agentapi new-conversation --model=<modelId>|send-message`, `WaitForConversationFullyIdle` + `CORTEX_STEP_STATUS_WAITING` approvals, reports from `GetCascadeTrajectorySteps|GetTrajectoryFileDiffs|GetCascadeTrajectoryGeneratorMetadata`. Hooks know delegated runs by `conversation.DELEGATED_MARK` (no setup/review/CI/recent-conversation/memory nudges). The agent's `ask|tell` only print a `{"to_claude_code": …}` line that `listen()` (→ record `chat`) finds in the RUN_COMMAND output or a backgrounded command's SYSTEM_MESSAGE `agentMessage`. `watch`, `wait` (exit 4 on a question), `reply`. Summary IDLE while `WaitForConversationFullyIdle` blocks = turn over, background work running: `background` (`idle_state()`). `auto_resume()` answers an `EXECUTOR_TERMINATION_REASON_ERROR` turn with «go on» (≤ `retries_max`, once per error: `transact()`); `--max-parallel` queues `q-…` records for `dispatch()` (`wait`/`watch`, or the detached `supervise`); `watch` claims events (`claim_events()`) and leases tasks (`watcher`); reports show `taskDetails` background commands (with PIDs) and `VIEW_FILE` images, and save per-turn `costs` for `estimate`. `--model orchestrator` = Orchestrator (Carbon), though Antigravity lists Orch (Neon) first (`fuzzy()`: fewest extra words). guard auto-approves only the installed script as one plain command (`talks_to_claude()`); Stop leaves an agent alone during `waiting_for_claude()`.
- `tests/` — offline process tests; `tests/probe/fake_lsp.py` is `test_lsp.py`'s fake server.

## Conventions
- **Zero external deps:** Python 3.8+ stdlib only (`from __future__ import annotations`); hooks on macOS often get `/usr/bin/python3` (3.9); CI: 3.9 & 3.13 on Ubuntu/macOS/Windows.
- **Cross-platform I/O:** `hooks/compat.py` for locks and atomic replace; `-X utf8` and `encoding="utf-8", errors="replace"` on `subprocess(..., text=True)` (Russian Windows pipes are cp1251); no invalid string escapes (`r"""…"""`). `tests/test_names.py` enforces both.
- **Public repo hygiene:** never include real hostnames, emails, private project names, bundle IDs, device names, or verbatim user chat quotes — use neutral synthetic examples.
- **Rule files:** `antigravity-plus/rules/*.md` require `trigger: always_on` YAML frontmatter and must stay `< 24 KB`; keep repo `AGENTS.md` `< 18.5 KB` so Antigravity never excludes it under its 20,000-token `rules-token-budget`.

## Gotchas
- Repo edits do **not** affect the live install until `./install.sh` runs.
- `sidecar_sdk` verifies `X-Sidecar-Token` only on non-GET requests: register stateful Control Center endpoints with `app.api(path, fn)` (POST), never `'GET'`.
- Automations (2.32.2): `~/.gemini/config/sidecars/<id>/sidecar.json` with `"builtin": "schedule"`, `"args": ["CRON_TZ=<zone> <cron>", "agentapi", "new-conversation", "--", "<prompt>"]` (a list), `"restart_policy": "always"`, `display_name`, `agent_permissions`; only the user enables one (Automations dashboard); unattended runs deny every command not granted. `/schedule-task` owns `agp-*`; guard asks before writes there (`scheduled-sidecar`).
- `index.html`, `usage.py`, `pricing.json` reload per request; `server.mjs` needs a `ManageSidecar` restart of `antigravity-plus/usage`.
- Language server (2.34.0+): no CSRF token on its command line; it writes `~/.gemini/antigravity/daemon/hub_<httpPort>.json` (0600: `pid`, `httpsPort`, `httpPort`, `lsVersion`, `csrfToken`). Agent terminals and sidecars get `ANTIGRAVITY_LS_ADDRESS` + `ANTIGRAVITY_CSRF_TOKEN`; hooks only `ANTIGRAVITY_CONVERSATION_ID`; the MCP server only `PLUGIN_ROOT`/`PLUGIN_DATA`. Always use `compat.language_server()`: env → daemon file (alive pid, `/healthz`) → `--csrf_token` (≤ 2.33). Never `os.kill(pid, 0)` on Windows: it terminates the process.
- Agent terminal: TTYs, `TERM=dumb`, `PAGER=cat`, `GIT_EDITOR=false` (use `GIT_EDITOR=true git …`); keyboard prompts hang.
- Hooks read settings via `skills/memory/scripts/memory.py`: it stays installed without the memory module (only `SKILL.md` goes); skill-backed nudges check the script exists.
- LSP: pyright knows only open files until «Found N source files» (`Session.ready`); sourcekit-lsp needs `buildServer.json` and a fresh build; kotlin-lsp needs the Gradle root and `kill_tree`.
- `agents/*.md` goes through `filter_rules`: a `<!-- needs:<skill> -->` line vanishes without that skill — keep such lines single.
- `tests/test_names.py` (`symtable`, Python 3.9) treats parameters of a function named `top` as globals — never name a function `top`.
- Hooks must never crash on malformed input; `PreToolUse` returning `{}` means **deny** (`{"decision": "allow"}` passes through).
- Bypass Mode: `/bypass`, `/bypass off`; `bypassMode` {on, at, since, conversation, n} in `settings.json`, set only by typed user messages (not briefs, subagents, `agentapi`), applied once per conversation (`bypass_applied`) and only if newer than `at`: an old «/bypass» never undoes a later «/bypass off».
- `delegate.py` runs with a copy of `hooks/compat.py`; `MARK` = `conversation.DELEGATED_MARK`, `ANSWER`/`MESSAGE`/`FOLLOW_UP` match `conversation.CLAUDE_SAYS` (`test_delegate.py`). `talk_in()` holds at an unfinished step; a «finished» verdict re-reads the whole turn.
- `usage.py` prices `agentapi` conversations via `started_on()`: task record → `GetCascadeTrajectoryGeneratorMetadata` → `conversation-models.json` → `default_model`; LS via `compat.daemon_servers()` (`ProxyHandler({})`). `AGY_CLI_AUTO_COMPACT_OVERRIDE` (`800K`, `80%`) is an Antigravity CLI setting only; the desktop app ignores it. `TIERS` hold live `modelId`s: update on a rename. `pick()` reorders a tier by each quota group's `state_of()`; `claude_limits()` only changes `advice()`.
- Orchestrator (fixed `gemini-pro-orchestrator[-argon|-neon]`; configurable Planner/Executor in Settings > Models and `/plan`, 2.34+): the planner (plan mode: reads, probes, edits nothing) hands over with `exit_plan_mode`; a SYSTEM_MESSAGE «Plan mode is off: this turn runs on the execution model» follows and Hydrogen carries the plan out until `enter_plan_mode` hands back («[plan review] … planning model», a SYSTEM_MESSAGE body; a Claude Code `reply` doesn't). Configurable sessions omit `"orchestrator"` from `modelName` and set `plan_execute:true` in `<appDataDir>/annotations/<cid>.pbtxt` (`is_plan_execute()`); only the configurable one defaults to High effort. Transcripts don't name a call's model: `usage.py` asks `GetCascadeTrajectoryGeneratorMetadata` (a call's `stepIndices` start at its own PLANNER_RESPONSE step), else `EXECUTION_RE`. Quota groups list «Orchestrator (Carbon)» whole, so `delegate.group_of()` matches the whole label and the family.
- Measuring quota: `RetrieveUserQuotaSummary {"forceRefresh": true}`; the plain call answers from the LS cache (~5 min) — that made Orchestrator (Carbon) look ~7× cheaper than Carbon (High) on 2026-11-17, really 10–15%. Forced reads show each call booked within seconds at its API price (per token Hydrogen 1, Neon 2, Carbon ~4). Claude group ≈ 2.5% of its week per API $ (Gemini ≈ 0.042%).
- Tiers (2.33–2.35.1; Neon $3/$15/$0.15): `fast` Hydrogen Low → Hydrogen Medium → Neon Low → Claude Sonnet 5.5 Low; `standard` Hydrogen Med → Neon Low → Hydrogen High → Neon Med → Sonnet Med; `strong` Neon Med → Hydrogen High → Neon High → Hydrogen XHigh → Orch Neon; `ultra` Carbon High → Orch Carbon → Carbon Med → Neon High; `claude` Sonnet → Opus. `delegate.EXPERIMENTAL` = un-tiered models (`Neon XHigh`, `Carbon Low`, `Opus Low`, `Argon`, `Orch Argon`, `3.8 Flash`, `GPT-OSS`). Antigravity tags Argon, 3.8 Flash and GPT-OSS as leaving on 2026-11-30 (not Orch Argon); AI Pro got Neon + Orch (Neon), not Carbon.
- Benchmarks: 2026-11-20 (2.33.0; 5 hidden-test tasks, 48 runs, 16 models: all right but Hydrogen (Low) once; Carbon (High) & Orch (Carbon) 11–26 min, 4–12× Hydrogen, never better) and 2026-11-24 (2.35.0; 20 runs, ≈ $10.5, pass rates only from its report; every Carbon (High)/Orch (Carbon) run hit the 9-minute cap). Don't lower `--timeout` (default 1800 s) for `ultra`.
- A new conversation's first call reads its prompt uncached (~41k tokens, 2026-11-25); later calls ~90% cached: chain work with `run --series` + `next`.
- Context windows (`maxContextTokens`, server-side; no `compaction_threshold`): per model from recent calls (`hooks/context_window.py`), else pricing.json's `context_window` (512k Gemini 4, 840k Claude 5.5, 256k 3.x Flash). Antigravity compacts when the next call won't fit, by the model-reported count (flag `use-model-reported-token-count`): max seen 511.8k of 512k; a big tool result can trigger it earlier. `speed.ctx_limits()` warns at 200k/440k (512k), 150k/220k (256k), 80k/110k (128k), 50k/70k (80k), the second scaled to a read window.
- An injected `systemMessage` persists until compaction: hint only on state changes (`<user_instructions>` ≤ every 100 steps, background hints once per conversation, `<other_agents>` on peer changes). `doctor.py` checks `RULE_FILE_LIMIT` (24,000 bytes).
